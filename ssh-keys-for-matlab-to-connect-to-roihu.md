## Background
To connect to Roihu, users must sign their public key in MyCSC to obtain a time-based SSH certificate. Each certificate is valid for 24 hours, and once it expires, a new one must be generated by signing the public key again.  See the [CSC SSH certificate instructions](https://docs.csc.fi/computing/connecting/ssh-keys/#signing-public-key) for a complete set of instructions.

① **One-time setup:** Complete marked steps once per machine or SSH key.

<a id="windows"></a>

## Windows

<a id="windows-generate-key"></a>

### Generate key ①

Run PowerShell **as non-administrator** to generate key.

```powershell
New-Item -ItemType Directory -Force "$HOME\.ssh" | Out-Null
ssh-keygen -a 100 -t ed25519 -f "$HOME\.ssh\csc_ed25519"
```

Enter a passphrase when prompted.

<a id="windows-add-public-key"></a>

### Add public key in MyCSC ①

1. Log in to [MyCSC](https://my.csc.fi) with your CSC or Haka/Virtu credentials
1. Select Profile from the left-hand navigation or the dropdown menu in the top-right corner
1. Locate SSH PUBLIC KEYS section and select + Add key
1. Add your public key (`$HOME\.ssh\csc_ed25519.pub`) by uploading the public key file in the Upload file tab
1. Select Upload or Add.  You should now see your new key listed under SSH PUBLIC KEYS.  **This might take up to one hour for your new key to become active.**

<a id="windows-sign-public-key"></a>

### Sign public key, download certificate

1. Log in to [MyCSC](https://my.csc.fi) with your CSC or Haka/Virtu credentials
1. Select Profile from the left-hand navigation or the dropdown menu in the top-right corner
1. Locate SSH PUBLIC KEYS section and click the three vertical dots next to the public key you want to sign
1. Click Sign and download SSH certificate

Run PowerShell **as non-administrator** to copy file into SSH folder.

```powershell
# Copy the downloaded certificate into SSH folder
Copy-Item "$HOME\Downloads\cert.pub" "$HOME\.ssh\csc_ed25519-cert.pub"
```
Substitute the actual downloaded certificate.

<a id="windows-start-agent"></a>

### Start Agent ①

Run PowerShell **as administrator** to start the Agent.

```powershell
# Change the ssh-agent Windows service's startup configuration to Automatic
Set-Service -Name ssh-agent -StartupType Automatic

# Tell Windows Service Controller to start ssh-agent now. If the service is
# already running, Start-Service ignores the request without error.
Start-Service ssh-agent
```

<a id="windows-add-private-key"></a>

### Add private key to agent

Run PowerShell **as non-administrator**

```powershell
# Load CSC private key
ssh-add "$HOME\.ssh\csc_ed25519"

# Verify key has been loaded
ssh-add -l

# Display certificate validity
ssh-keygen -L -f "$HOME\.ssh\csc_ed25519-cert.pub" | Select-String "Valid"
```

<a id="windows-test"></a>

### Test

Run PowerShell **as non-administrator** (change \<username\>).

```powershell
ssh <username>@roihu-cpu.csc.fi pwd
```

From MATLAB, run

```matlab
rca = parallel.cluster.RemoteClusterAccess("<username>",AuthenticationMode="Agent");
rca.connect("roihu-cpu.csc.fi")
[~, home_dir] = rca.runCommand("pwd")
```

The output from the PowerShell and MATLAB commands should return the same string.

<a id="linux-macos"></a>

## Linux / macOS

<a id="linux-generate-key"></a>

### Generate key ①

From Terminal, generate key.

```shell
ssh-keygen -a 100 -t ed25519 -f ~/.ssh/csc_ed25519
```
Enter a passphrase when prompted.

<a id="linux-add-public-key"></a>

### Add public key in MyCSC ①

1. Log in to [MyCSC](https://my.csc.fi) with your CSC or Haka/Virtu credentials
1. Select Profile from the left-hand navigation or the dropdown menu in the top-right corner
1. Locate SSH PUBLIC KEYS section and select + Add key
1. Add your public key (`~/.ssh/csc_ed25519.pub`) by uploading the public key file in the Upload file tab
1. Select Upload or Add.  You should now see your new key listed under SSH PUBLIC KEYS.  **This might take up to one hour for your new key to become active.**

<a id="linux-sign-public-key"></a>

### Sign public key, download certificate

1. Log in to [MyCSC](https://my.csc.fi) with your CSC or Haka/Virtu credentials
1. Select Profile from the left-hand navigation or the dropdown menu in the top-right corner
1. Locate SSH PUBLIC KEYS section and click the three vertical dots next to the public key you want to sign
1. Click Sign and download SSH certificate

From Terminal, copy file into SSH folder.

```shell
# Copy the downloaded certificate into SSH folder
cp ~/Downloads/cert.pub ~/.ssh/csc_ed25519-cert.pub
```
Substitute the actual downloaded certificate.

<a id="linux-start-agent"></a>

### Start Agent

From Terminal:

```shell
# Generate SSH environment variables needed to start agent
eval "$(ssh-agent -s)"
```

<a id="linux-add-private-key"></a>

### Add private key to agent

From Terminal:

```shell
# Load CSC private key
ssh-add ~/.ssh/csc_ed25519

# Verify key has been loaded
ssh-add -l

# Display certificate validity
ssh-keygen -L -f ~/.ssh/csc_ed25519-cert.pub | grep "Valid"
```

The output from the shell and MATLAB commands should return the same string.
